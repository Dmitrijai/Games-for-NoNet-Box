Перенос 3D-лавовой лампы с физикой в Blender

Два способа открытия в Blender (3.x / 4.x / 5.x):
  • Способ 1 — Нативный генератор .py → .blend (Рекомендуется): создаёт внутри Blender настоящие метаболы (bpy.data.metaballs), которые плавно сливаются и разлипаются в единую бесшовную поверхность воска на каждом кадре, собирает PBR-материалы стекла (IOR 1.52), жидкости и воска с подповерхностным рассеиванием (Subsurface Scattering) и автоматически сохраняет готовый файл lava_lamp_custom_animated.blend!
  • Способ 2 — Прямой импорт .gltf: открывается через File → Import → glTF 2.0 (.glb/.gltf) с готовой геометрией и 3D-ключами анимации всех капель.

Как запустить генератор .blend за 5 секунд в Blender:

  1. Нажмите кнопку «Скачать для Blender (.py → .blend)» (скрипт сохранит ваши текущие цвета, форму колбы и запечёт физику движения капель).
  2. Откройте Blender, перейдите во вкладку Scripting в верхнем меню.
  3. Нажмите Open, выберите скачанный файл lava_lamp_custom_scene.py (или скопируйте код ниже в буфер обмена и вставьте в редактор Blender).
  4. Нажмите кнопку Run Script (▶) — вся 3D-модель с материалами и анимацией построится автоматически и сохранится в готовый файл .blend!
